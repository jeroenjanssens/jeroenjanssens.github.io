# jeroenjanssens.github.io

Redirects to [jeroenjanssens.com](https://jeroenjanssens.com/), keeping the path.
`index.html` and `404.html` are identical: GitHub Pages serves `404.html` for
every path that doesn't exist, so all URLs redirect.

Project sites (e.g. `jeroenjanssens.github.io/<repo>/`) are served from their
own repos and aren't affected.

The site that lived here until 2026 is archived in
[old-site-2021](https://github.com/jeroenjanssens/old-site-2021).
